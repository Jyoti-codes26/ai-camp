# Theme: Kinetic Terminal — Portfolio Website PRD

## Purpose

Create a portfolio website that presents my projects, details, skills and education clearly.

## Audience

Recruiters and visitors who want to know more about my projects, skills and education. It can also be interviewers.

## Main goals

- Explain the projects I have worked on
- Explain who I am quickly
- Show my strongest projects
- Make my skills easy to scan
- Provide a clear contact action

## Required sections

The portfolio website scaffold must follow this exact section order:
1. Header / Navigation
2. Hero / Overview (Quick intro, role, status)
3. About / Profile Summary
4. Skills
5. Projects Showcase
6. Education
7. Certifications
8. Contact
9. Footer / Engineering Footnote

## Required behaviours

- Should work on mobile and desktop
- Should be easy to navigate
- Should be fast
- Project links should work
- Easy to understand
- The layout should work on small screens

## Features

- Interactive project category filters (All, AI & ML, Cybersecurity, Software Dev)
- Technical telemetry badges and status indicators
- Responsive navigation (mobile bottom nav bar, desktop top bar)
- Accessible high-contrast typography adhering to Kinetic Terminal specs
