## Staged Execution Constraints

> **CRITICAL RULE:** Do NOT begin implementation immediately. Development must occur strictly in stages. Do NOT advance to any subsequent stage until explicit user confirmation is received.

### Mandatory Stages:

1. **Stage 1: Page Structure Only**
   - Create the section scaffold in the exact order given in `prd.md`.
   - Headings and placeholder blocks only.
   - Strictly NO styling, NO content, NO components.

2. **Stage 2: Visual Design**
   - Apply the colors, typography, spacing, and hierarchy from `DESIGN.md` to the page structure.
   - Strictly do NOT add content. Do NOT add components.

3. **Stage 3: Real Content**
   - Replace the placeholders with the content attached in `Profile.pdf`.
   - Use ONLY content from `Profile.pdf`.
   - If something is missing from `Profile.pdf`, leave the section empty and report what is missing — do NOT fill the gap and do NOT write filler text.

4. **Stage 4: Components & Interactivity**
   - Implement functional components, category filters, interactive states, and responsive navigation.

5. **Stage 5: Final Polish & Verification**
   - Verify layout and behavior across mobile and desktop viewport sizes, ensuring speed, fast navigation, and valid links.
